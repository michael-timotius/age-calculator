New Skills Created
L3 Ops — 4 skills
Behavioral contracts that were missing entirely. Lifecycle logic was previously embedded in L1/L2 skills — extracted and formalized.
rewards-ops-award-points
L3 Ops
Admin awards points to a member. Covers tier bonus calculation, optional Level EXP co-grant, and notification dispatch.
  • Actor: Community Admin only
  • Effective amount = base × (1 + tier bonus%)
  • Triggers in-app + web push notification
  • Optional Level EXP co-grant (not Tier)
  • MemberReward + EarnedRewardPoint both append-only
rewards-ops-manage-catalog
L3 Ops
Admin creates, configures, and disables redeemable items. Covers all 4 limitation types and soft-disable via expiry.
  • Limitation types: none / per_member / global_stock / both
  • VIP flag — filtered server-side, not client-side
  • Disable = set expired_at to now (irreversible via UI)
  • Existing On Process requests unaffected on disable
rewards-ops-exchange-request
L3 Ops
Member submits exchange request. Documents all 6 validation gates in order with exact rejection messages.
  • Gate 1: item availability (window + disabled)
  • Gate 2: VIP gate (Stage ≥ 50 + vip_access_enabled)
  • Gate 3: global stock
  • Gate 4: per-member cap
  • Gate 5: daily redemption limit (from Level stage)
  • Gate 6: sufficient point balance
rewards-ops-fulfill-exchange
L3 Ops
Admin completes or rejects; member cancels own request. Documents terminal-state rule and +20 Tier EXP on completion.
  • Complete/Reject: admin only
  • Cancel: requesting member only
  • Completion = +20 Tier EXP (fixed, never configurable)
  • Rejected/Cancelled = points returned to balance
  • Terminal states: no further transitions possible
